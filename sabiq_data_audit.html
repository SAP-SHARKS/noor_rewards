Bottom line

  • No analytics, crash-reporting, ads, or attribution SDKs are present in the app.
  • Only third-party services that receive user data are Google (Sign-In and FCM push infrastructure) and two IP→country lookup APIs (api.country.is, ipapi.co) — IP is never persisted, only the resulting 2-letter country code is stored in Supabase.
  • Location coordinates are never persisted — GPS lat/lng are read, converted to an IANA timezone string in memory, then discarded.
  • All aggregated user data (XP, streaks, bookmarks, donations, session activity) lives in Supabase, which is self-hosted / owner-controlled.
  • All Android permissions and iOS usage descriptions map to concrete features listed above — no unused permissions.
